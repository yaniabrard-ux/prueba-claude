# Grafix — Sitio web

Sitio estático (HTML/CSS/JS, sin build) para Grafix, imprenta de Salsipuedes, Córdoba.
Servicios destacados: etiquetas, cartelería, sublimación y fotos.

## Estructura

```
index.html
assets/
  css/style.css
  js/main.js
```

## Ver en local

Abrir `index.html` en el navegador, o levantar un servidor simple:

```bash
python3 -m http.server 8000
```

y entrar a `http://localhost:8000`.
